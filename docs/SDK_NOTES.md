# SDK notes

Validated against published `@heliuslabs/spr@0.9.0-alpha` and `@solana/kit@8.6.0`. The Helius transfer guide requires Node 24, so the repository and deployment use Node 24. The old zolana source URL redirects to privacy-rings. The current repository documents CLI installation under the `spr-cli` crate while the resulting binary is `zolana`.

The SDK provides high-level `buildDepositTransaction`, `syncWallet`, `getPrivateTokenBalances` and `getPrivateTransactions`. Its transaction compiler emits version 1 and uses the v1 account data budget. Webpack explicitly resolves the two published Light Protocol hasher WASM assets from the dependency's dist directory. The installed package references bare WASM names inside nested JavaScript files.

## Known gaps

- **Browser-only spend proofs.** VEIL uses the published `@heliuslabs/spr-web-prover@0.7.0-alpha` with client-fetched Merkle data. The browser worker intercepts the SDK proving route and the fallback transport rejects that origin. Runtime key downloads use the package pins. The client uses single-thread proving for compatibility with wallet popups and has no remote proof fallback. Next.js emits the workers with a circular chunk hash warning. [Helius browser SDK](https://github.com/helius-labs/privacy-ring-web-sdk)
- **Atomic deal and expiry refunds.** The multi-transfer wallet helper sends one owner's asset to multiple outputs. It is not a two-owner, two-asset OTC coordinator. Upstream demonstrates swap and escrow circuits with insecure deterministic test keys. TODO verify a complete two-party composition with independently authorized inputs and a confidential fee in one transaction, or design and review a production escrow circuit and timelock refund path. Keep funding disabled until that path is independently verified. [Example programs and test-key warning](https://github.com/helius-labs/privacy-ring-examples)
- **Wallet and cluster compatibility.** Deposit requires an extension and cluster that support version 1. Phantom, Solflare and Backpack acceptance on the selected network remains unverified. A public deposit is optional and disabled by default. [Helius endpoints](https://www.helius.dev/docs/privacy/endpoints) · [SDK](https://www.helius.dev/docs/privacy/sdk)
- **Market data and treasury.** Size buckets are manually selected. Jupiter price lookups, fee collection, token-holder discounts, reputation backed by seals, and the buyback-burn worker are pending. The burns page reports the job as unavailable. [Jupiter docs](https://developers.jup.ag/docs)
- **Infrastructure and delivery.** This build uses SQL migrations in place of Prisma, CSS in place of Tailwind/shadcn, and polling in place of SSE. The vault passed a two-wallet Playwright test on zolana localnet. Full OTC integration, funded devnet Playwright, hosted deployments, and remote CI execution remain pending. Fastify exposes an OpenAPI UI with route discovery. Schema and response documentation cover only what the server registers through Fastify. The API provides a screening interface and OFAC adapter. A commercial adapter and a shared rate-limit store are pending.
